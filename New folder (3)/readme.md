# AgriSmart: Crop Advisory System 🌾

AgriSmart ek intelligent web application hai jo Pakistani kisaano aur gardeners ko unki mitti (soil) aur real-time weather ke mutabiq behtreen faslon (crops) ka mashwara deti hai.

## ✨ Features
- **3D Interactive UI:** Three.js ka istemal karke ek immersive animated background banaya gaya hai.
- **Real-time Weather Integration:** OpenWeather API ke zariye live temperature check karke mashwara milta hai.
- **Crop Database:** Pakistan ki mitti aur season (Rabi/Kharif) ke mutabiq mukammal database.
- **Responsive Design:** Mobile aur desktop dono par behtreen chalta hai.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Glassmorphism UI)
- **Graphics:** Three.js (3D Particles System)
- **Logic:** Vanilla JavaScript (ES6+)
- **API:** OpenWeatherMap API
